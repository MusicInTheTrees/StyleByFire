# Textile background assets

Generated with the built-in image generation tool. Each source was a sock photograph supplied by the app owner as a pattern reference. Original photographs remain private; the outputs are flat textile backgrounds.

## diamond

Use case: stylized-concept. Asset type: seamless square textile-pattern background for the StyleByFire wardrobe app, filling a fixed layer behind interface cards. Primary request: create a refined all-over wallpaper inspired specifically by the large thin outlined diagonal diamond grid on the blue socks, clean straight navy-blue lines on a soft slate-blue field. Input image is a PATTERN REFERENCE ONLY: use the motifs printed/knitted on the socks, not the fabric underneath the socks. Extend the sock motif into a completely flat, edge-to-edge 2D pattern. Consistent upscale designer-blue and cool-gray palette across the entire image: soft slate, denim blue, powder blue, subtle silver-gray. Medium-light base, restrained contrast, a faint woven-knit grain, crisp orderly geometry. Approximately 12–18 repeats across the image, evenly spaced, scalable for a desktop app. No focal object, no perspective, no gradients or vignettes, no folds, no photographed socks, no feet, no furniture, no background cloth, no text, no borders, no logos. Output one square seamless pattern image, suitable to tile quietly behind readable navy UI text.

Output: `app/ambient-diamond.png`
