# StyleByFire interface packs

These six selectable packs affect the application interface only. The photos, photo adjustments, garment color swatches, mannequin image files, and styling decisions retain their saved values. The five new packs use original CSS gradients drawn at low opacity; Designer Blue retains the app's four existing blue pattern assets. No retailer image, textile print, or logo is used as a theme asset.

The palettes below are design choices inspired by the mood and materials in the linked catalogs, not color samples lifted from their photographs. Text, button, sidebar, and status pairings in all packs meet at least 4.5:1 contrast in `tests/theme-packs.test.mjs`. The focus outline uses each pack's distinct focus color. The background is fixed; users can keep one pattern, allow an 18-second cycle with a six-second crossfade, or choose a solid color. Reduced-motion mode disables the cycle and fade.

## Preview and behavior

Settings shows a four-surface preview for each pack: wardrobe cards, a saved look, Settings controls, and an outfit designer card. When clothing is present, preview tiles use the app's normal photo renderer, including saved photo adjustments. Selecting a pack applies it immediately and stores only its ID in browser local storage. **Restore Designer Blue** resets that ID. This setting is local to this browser, separate from wardrobe records and outfit preferences.
